Take the current conversation context and produce a PRD. Do NOT interview — synthesize what you already know.

## Process

1. Explore repo; use domain glossary
2. Sketch major modules; look for deep module opportunities
3. Confirm modules with user
4. Write and publish PRD with `ready-for-agent` label

## Template sections

- Problem Statement
- Solution
- User Stories (extensive numbered list)
- Implementation Decisions
- Testing Decisions
- Out of Scope
- Further Notes

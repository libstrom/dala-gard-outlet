# Triage

Move issues through a triage state machine. Every AI-generated comment must start with:

```
> *This was generated by AI during triage.*
```

## Roles

Category: `bug`, `enhancement`

State: `needs-triage` → `needs-info` ↔ `needs-triage` → `ready-for-agent` / `ready-for-human` / `wontfix`

Run `/setup-matt-pocock-skills` if label mapping hasn't been provided.

## Invocation

Natural language: "show me what needs attention", "triage #42", "move #42 to ready-for-agent".

## Show what needs attention

Three buckets, oldest first: Unlabeled → needs-triage → needs-info with recent activity.

## Triage a specific issue

1. Read full issue + prior triage notes
2. Recommend category + state with reasoning, wait for direction
3. Reproduce (bugs only)
4. Grill with `/grill-with-docs` if needed
5. Apply outcome: update labels, post comment or agent brief, close if wontfix
